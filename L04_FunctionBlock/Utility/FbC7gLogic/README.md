# FbC7gLogic：C7G 邏輯功能獨立規劃（尚未實作）

## 摘要

2026-10-21 決定將 C7G 邏輯功能與現有 FbLogic 分開。`FbLogic` 以 DTDM04 的單一邏輯運算功能為基準；`FbC7gLogic` 為另一個獨立 FB 的規劃名稱，目前只有規劃文件，沒有正式介面、程式或測試，不加入建置。

既有 FbLogic 的實作與測試結果不能視為 FbC7gLogic 已完成。兩者需各自定義參數、狀態、完成條件與測試，不以新增 FbLogic 模式混合兩套設備語意。
